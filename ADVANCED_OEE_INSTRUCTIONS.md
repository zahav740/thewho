## 🎯 КАК ПОЛЬЗОВАТЬСЯ

### ЕЖЕДНЕВНЫЙ ВВОД ДАННЫХ:
1. Откройте лист **"Data"**
2. В новой строке заполните:
   - **Date**: дата
   - **Station**: выберите из списка (Doosan_Yashana, etc.)
   - **Operator**: выберите из списка (Andrey, Denis, etc.)
   - **Shift_min**: обычно 480 (8 часов)
   - **Setup_min**: время наладки в минутах
   - **Downtime_min**: время простоев
   - **Planned_pcs**: планируемое количество деталей
   - **Actual_pcs**: фактически произведено
   - **Defect_pcs**: количество брака

3. **Production_remaining** рассчитается автоматически
4. Все остальные показатели (OEE, KPI) рассчитаются автоматически

### АНАЛИЗ РЕЗУЛЬТАТОВ:

#### ОБЩАЯ КАРТИНА:

#### ПО ОПЕРАТОРАМ:

## 🔢 КЛЮЧЕВЫЕ ФОРМУЛЫ

### ОСТАТОК ПРОИЗВОДСТВА:
```
Production_remaining = Предыдущий_остаток - Actual_pcs + Defect_pcs
```

### OEE:
```
OEE = Availability × Performance × Quality / 10000
Availability = (Shift - Downtime) / Shift × 100%
Performance = Actual / Planned × 100%
Quality = (Actual - Defect) / Actual × 100%
```

### KPI:
```
KPI = OEE×50% + (100-Setup_ratio)×20% + Setup_quality×15% + 90×15%
```

## 🎨 ЦВЕТОВЫЕ ИНДИКАТОРЫ

### OEE И KPI:
- 🟢 **Зеленый**: Отличные результаты (≥80% OEE, ≥85% KPI)
- 🟡 **Желтый**: Хорошие результаты (70-79% OEE, 75-84% KPI)
- 🔴 **Красный**: Требует улучшения (<70% OEE, <75% KPI)

### СТАТУСЫ:
- 🏆 **Excellent**: Лучшие результаты
- ✅ **Good**: Хорошие результаты
- ⚠️ **Needs Attention**: Требует внимания

## 🔧 УСТРАНЕНИЕ ПРОБЛЕМ

### Если формулы не работают:
1. Проверьте, что Excel на английском языке или поддерживает английские формулы
2. Убедитесь, что разделитель десятичных знаков - точка (.)
3. Перезапустите Excel и откройте файл заново

### Если выпадающие списки не работают:
1. Убедитесь, что ячейки не заблокированы
2. Проверьте, что лист не защищен паролем

### Если цвета не отображаются:
1. Проверьте, что условное форматирование включено
2. Убедитесь, что в ячейках есть числовые значения
