## 🚀 Как запустить

### 1. Откройте приложение
Перейдите в браузере по адресу: `http://localhost:3000/column-templates`

### 2. Что вы увидите
- **Переключатель режимов** в правом верхнем углу
- **Демо версия включена по умолчанию** 
- **Полнофункциональный интерфейс** управления колонками

### 3. Попробуйте демо
- ✅ Выберите/отмените колонки галочками
- ✅ Посмотрите на умные предложения (зеленые галочки)
- ✅ Нажмите "Сохранить как шаблон"
- ✅ Попробуйте кнопки управления шаблонами

## 🎯 Что работает в демо

### Автоматическое распознавание
```javascript
// Примеры умных предложений
'Название товара'  → ✅ product_name   (рекомендуется)
'Количество'       → ✅ quantity       (рекомендуется)
'Цена'            → ✅ price          (рекомендуется)
'№ п/п'           → ❌ row_number     (пропускается)
'Комментарий'     → ❌ comment        (пропускается)
```

### Интерактивный выбор
- **Визуальные карточки** для каждой колонки
- **Цветовая индикация** выбранных колонок
- **Счетчик выбранных** колонок
- **Предпросмотр** системных названий

### Управление шаблонами
- **Список сохраненных** наборов
- **Статистика использования** каждого шаблона
- **Установка по умолчанию** любого набора
- **Действия с шаблонами** (применить, редактировать, удалить)

## 🔧 Для полноценной работы

Когда захотите использовать реальную версию:

### 1. Выполните миграции
```bash
cd backend
npm run migration:run
```

### 2. Перезапустите backend
```bash
npm run start:dev
```

### 3. Переключитесь на реальную версию
Нажмите кнопку "🔧 Реальная версия" в интерфейсе

### 4. Загрузите Excel файл
- Перейдите в раздел загрузки Excel
- Загрузите файл и получите его ID
- Введите ID в поле на странице управления колонками
