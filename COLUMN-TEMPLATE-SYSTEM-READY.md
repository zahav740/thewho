# Column Template System - Система управления колонками

Создана упрощенная и гибкая система для работы с колонками Excel файлов.

## ✅ Что реализовано

### 🔍 Автоматическое распознавание колонок
- **Анализ по индексам**: Система автоматически находит все колонки в Excel файле
- **Умные предложения**: Автоматически определяет, какие колонки стоит включить
- **Предложение названий**: Генерирует подходящие системные названия для колонок

### 🎯 Гибкий выбор колонок
- **Визуальный интерфейс**: Удобное выбор колонок из обнаруженного списка
- **Переименование**: Возможность задать свои названия для колонок в системе
- **Сортировка**: Настройка порядка колонок в выгрузке
- **Предпросмотр**: Видно, какие колонки будут включены и в каком порядке

### 💾 Сохранение наборов
- **Пользовательские шаблоны**: Сохранение своих наборов колонок
- **Набор по умолчанию**: Установка любого набора как дефолтный
- **Замена шаблонов**: Возможность изменить любой сохраненный набор
- **Управление**: Создание, редактирование, удаление наборов

## 🚀 Как это работает

### 1. Загрузка файла и анализ
```
Пользователь загружает Excel → 
Система анализирует колонки → 
Показывает список обнаруженных колонок с предложениями
```

### 2. Создание набора колонок
```
Пользователь выбирает нужные колонки →
Настраивает их названия и порядок →
Сохраняет как именованный набор →
Может установить как дефолтный
```

### 3. Применение к файлам
```
При загрузке нового файла →
Система предлагает подходящие наборы →
Пользователь выбирает или создает новый →
Данные обрабатываются согласно набору
```

## 📋 API Endpoints

### Работа с колонками
```
GET    /api/excel-import/templates/detect-columns/:fileId  - Анализ колонок файла
POST   /api/excel-import/templates                        - Создание набора
GET    /api/excel-import/templates                        - Список всех наборов
GET    /api/excel-import/templates/default                - Набор по умолчанию
PUT    /api/excel-import/templates/:id                    - Обновление набора
DELETE /api/excel-import/templates/:id                    - Удаление набора
POST   /api/excel-import/templates/:id/apply-to-file/:fileId - Применение к файлу
```

## 🎨 Интерфейс

### Главный экран
- **Список наборов**: Все сохраненные пользователем наборы колонок
- **Статистика использования**: Сколько раз каждый набор применялся
- **Быстрые действия**: Применить, редактировать, удалить, установить по умолчанию

### Редактор колонок
- **Левая панель**: Все обнаруженные колонки с рекомендациями
- **Правая панель**: Выбранные колонки с возможностью сортировки
- **Настройки**: Переименование колонок для системы
- **Сохранение**: Название набора и установка по умолчанию

## 💡 Умные функции

### Автоматические предложения
Система анализирует названия колонок и предлагает:
- ✅ **Включить**: Полезные колонки (название, количество, цена, дата)
- ❌ **Пропустить**: Служебные колонки (№ п/п, комментарии, пустые)
- 🏷️ **Переименовать**: Подходящие системные названия

### Примеры предложений
```
Excel колонка          → Системное название    → Предложение
"Название товара"      → "nazvanie_tovara"     → ✅ Включить
"Количество"          → "kolichestvo"         → ✅ Включить  
"№ п/п"               → "nomer"               → ❌ Пропустить
"Комментарий"         → "kommentarij"         → ❌ Пропустить
```

## 🔧 Настройки

### Создание набора
```typescript
{
  name: "Основные товары",           // Название набора
  columnSelections: [
    {
      excelColumn: "Название товара", // Колонка в Excel
      systemName: "product_name",     // Название в системе
      include: true,                  // Включать в выгрузку
      order: 1                        // Порядок в выгрузке
    }
  ],
  isDefault: false                    // Установить по умолчанию
}
```

### Применение к файлу
```typescript
// Файл с исходными данными
[
  { "Название товара": "Хлеб", "Количество": 10, "Комментарий": "..." },
  { "Название товара": "Молоко", "Количество": 5, "Комментарий": "..." }
]

// После применения набора
[
  { "product_name": "Хлеб", "quantity": 10 },
  { "product_name": "Молоко", "quantity": 5 }
]
```

## 📊 Преимущества новой системы

### Для пользователя
- **Простота**: Интуитивный интерфейс выбора колонок
- **Гибкость**: Полный контроль над тем, что включать в выгрузку
- **Удобство**: Сохранение часто используемых наборов
- **Скорость**: Быстрое применение готовых шаблонов

### Для системы
- **Упрощение**: Меньше сложной логики валидации и преобразований
- **Производительность**: Только нужные колонки обрабатываются
- **Масштабируемость**: Легко добавлять новые типы анализа колонок
- **Поддержка**: Понятная структура данных
