### Суть исправления:
Заменил `this.logger` на локальные экземпляры `Logger` в функциях `fileFilter`:

```typescript
// Было:
this.logger.log('сообщение');

// Стало:
const logger = new Logger(ControllerName.name);
logger.log('сообщение');
```
