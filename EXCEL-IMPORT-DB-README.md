# Система импорта Excel с базой данных

## Обзор

Новая система импорта Excel предоставляет полноценный функционал для загрузки, обработки и управления Excel файлами с сохранением в базу данных PostgreSQL.

## Основные возможности

### 🗄️ Excel БД Менеджер
- Загрузка Excel файлов с сохранением в базу данных
- Просмотр истории всех импортов
- Детальная информация о каждом импорте
- Возможность повторного импорта с другими настройками
- Превью данных из загруженных файлов

### ⚙️ Менеджер фильтров импорта
- Создание и редактирование фильтров импорта
- Настройка валидации данных
- Маппинг колонок Excel к полям базы данных
- Поддержка разных целевых таблиц (заказы, операции)

## База данных

### Таблицы

#### excel_imports
Хранит информацию о загруженных Excel файлах:
- `id` - уникальный идентификатор
- `filename` - имя файла в системе
- `original_filename` - оригинальное имя файла
- `upload_date` - дата загрузки
- `status` - статус обработки (uploaded, processing, processed, error)
- `headers_count` - количество заголовков
- `rows_count` - количество строк данных
- `imported_to_orders` - импортировано ли в таблицу заказов
- `imported_to_operations` - импортировано ли в таблицу операций

#### excel_data
Хранит содержимое ячеек Excel файлов:
- `id` - уникальный идентификатор
- `excel_import_id` - ссылка на импорт
- `sheet_name` - название листа
- `row_number` - номер строки
- `column_name` - название колонки
- `cell_value` - значение ячейки
- `data_type` - тип данных (string, number, date, boolean)

#### import_filters
Хранит настройки фильтров импорта:
- `id` - уникальный идентификатор
- `name` - название фильтра
- `description` - описание
- `target_table` - целевая таблица (orders, operations)
- `filter_config` - JSON конфигурация фильтра
- `column_mapping` - JSON маппинг колонок
- `is_active` - активен ли фильтр

## API Endpoints

### Импорт Excel

#### POST `/api/excel-import-db/upload`
Загрузка и импорт Excel файла
- **Параметры:**
  - `file` (multipart) - Excel файл
  - `targetTable` (query) - целевая таблица (orders/operations)
  - `filterId` (query, опционально) - ID фильтра

#### GET `/api/excel-import-db/imports`
Получение списка импортов
- **Параметры:**
  - `page` (query) - номер страницы
  - `limit` (query) - количество на странице

#### GET `/api/excel-import-db/imports/:id`
Получение деталей импорта

#### POST `/api/excel-import-db/imports/:id/re-import`
Повторный импорт с другими настройками

### Управление фильтрами

#### GET `/api/excel-import-db/filters`
Получение списка фильтров
- **Параметры:**
  - `targetTable` (query, опционально) - фильтрация по целевой таблице

#### POST `/api/excel-import-db/filters`
Создание нового фильтра

#### PUT `/api/excel-import-db/filters/:id`
Обновление фильтра

#### DELETE `/api/excel-import-db/filters/:id`
Удаление фильтра

## Конфигурация фильтров

### Пример filter_config для заказов:

```json
{
  "required_columns": ["drawing_number", "quantity", "deadline"],
  "optional_columns": ["priority", "workType"],
  "data_validation": {
    "drawing_number": {
      "type": "string",
      "max_length": 100,
      "required": true
    },
    "quantity": {
      "type": "integer",
      "min": 1,
      "required": true
    },
    "deadline": {
      "type": "date",
      "required": true
    },
    "priority": {
      "type": "integer",
      "min": 1,
      "max": 10,
      "default": 5
    }
  },
  "skip_empty_rows": true,
  "header_row": 1
}
```

### Пример column_mapping:

```json
{
  "drawing_number": "drawing_number",
  "quantity": "quantity",
  "deadline": "deadline",
  "priority": "priority",
  "workType": "workType",
  "Номер чертежа": "drawing_number",
  "Количество": "quantity",
  "Срок": "deadline",
  "Приоритет": "priority",
  "Тип работы": "workType"
}
```

## Использование в интерфейсе

### Доступ к функциям
1. Перейдите в раздел "База данных"
2. Найдите кнопки импорта Excel:
   - **🗄️ Excel БД Менеджер** - основной инструмент импорта
   - **⚙️ Фильтры** - управление фильтрами

### Процесс импорта
1. Откройте Excel БД Менеджер
2. Выберите целевую таблицу (заказы/операции)
3. Выберите фильтр импорта (опционально)
4. Загрузите Excel файл
5. Просмотрите результаты импорта

### Настройка фильтров
1. Откройте Менеджер фильтров
2. Создайте новый фильтр или отредактируйте существующий
3. Настройте конфигурацию валидации данных
4. Настройте маппинг колонок Excel к полям БД
5. Сохраните фильтр

## Особенности реализации

### Backend (NestJS + TypeORM)
- **ExcelImportDbService** - основной сервис для работы с импортом
- **ExcelImportDbController** - REST API контроллер
- **Entity:** ExcelImport, ExcelData, ImportFilter

### Frontend (React + TypeScript)
- **ExcelImportManager** - основной компонент импорта
- **FilterManager** - компонент управления фильтрами
- Интеграция в DatabasePage

### Безопасность
- Валидация типов файлов (только .xlsx, .xls)
- Ограничение размера файлов (50MB)
- Валидация данных согласно настройкам фильтров
- Сохранение истории всех операций

## Устранение неполадок

### Файлы не сохраняются в список
- Проверьте доступность базы данных PostgreSQL
- Убедитесь, что таблицы созданы корректно
- Проверьте логи backend для ошибок

### Фильтры не работают
- Проверьте JSON синтаксис в конфигурации фильтра
- Убедитесь, что фильтр активен
- Проверьте соответствие названий колонок в маппинге

### Проблемы с импортом
- Убедитесь, что Excel файл содержит данные
- Проверьте соответствие структуры файла настройкам фильтра
- Проверьте логи для детальной информации об ошибках
