# Новая функция: Импорт Excel с выбором колонок

## 📋 Обзор

Добавлена новая функциональность для гибкого импорта Excel файлов с возможностью выбора и настройки соответствия колонок. Теперь пользователи могут импортировать заказы из Excel файлов любой структуры, настраивая соответствие колонок полям заказа.

## 🆕 Что добавлено

### Backend
1. **ExcelColumnMapperService** (`backend/src/modules/orders/excel-column-mapper.service.ts`)
   - Анализ структуры Excel файлов
   - Автоматическое определение типов данных в колонках
   - Предложение оптимального маппинга колонок
   - Импорт данных с пользовательским маппингом

2. **Новые API эндпоинты в OrdersController**:
   - `POST /api/orders/analyze-excel` - анализ структуры Excel файла
   - `POST /api/orders/import-excel-with-mapping` - импорт с пользовательским маппингом

### Frontend
1. **ExcelColumnMapper** (`frontend/src/components/ExcelUploader/ExcelColumnMapper.tsx`)
   - Модальное окно для настройки соответствия колонок
   - Пошаговый мастер настройки (выбор листа → настройка колонок → проверка)
   - Автоматические предложения соответствий

2. **AdvancedExcelUploader** (`frontend/src/components/ExcelUploader/AdvancedExcelUploader.tsx`)
   - Улучшенный компонент загрузки Excel с интеграцией маппера колонок
   - Поддержка множественных файлов
   - Отображение прогресса и результатов импорта

3. **ExcelImportDemo** (`frontend/src/components/ExcelUploader/ExcelImportDemo.tsx`)
   - Демо-страница для тестирования новой функциональности

## 🔧 Установка и настройка

### 1. Backend
Сервис уже добавлен в модуль orders и готов к использованию. Убедитесь, что в `orders.module.ts` включен `ExcelColumnMapperService`.

### 2. Frontend
Новые компоненты готовы к использованию. Для интеграции в существующие страницы:

## 📚 Как это работает

### 1. Анализ файла
При загрузке Excel файла система:
- Анализирует все листы и их структуру
- Определяет типы данных в каждой колонке (текст, число, дата)
- Анализирует заголовки и содержимое для предложения соответствий
- Рекомендует наиболее подходящий лист для импорта

### 2. Настройка соответствий
Пользователь может:
- Выбрать нужный лист из файла
- Настроить, какая колонка соответствует какому полю заказа
- Указать настройки для операций (начальная колонка, количество колонок на операцию)
- Указать настройки чтения (есть ли заголовки, с какой строки начинать)

### 3. Импорт данных
Система импортирует данные согласно настройкам и возвращает подробную статистику.

## 🎯 Поддерживаемые поля

- **Номер чертежа** (обязательное) - уникальный идентификатор заказа
- **Количество** - количество изделий для производства
- **Срок выполнения** - дедлайн заказа
- **Приоритет** - приоритет заказа (критический, высокий, средний, низкий)
- **Тип работы** - описание типа работы
- **Операции** - последовательность производственных операций

## 📊 Примеры поддерживаемых структур

### Пример 1: Стандартная структура
```
A: Номер чертежа | B: Количество | C: Срок | D: Приоритет | E: Тип работы | F-K: Операции
```

### Пример 2: Произвольное расположение
```
C: Drawing Number | E: QTY | H: Deadline | K: Priority | L-P: Operations
```

### Пример 3: С дополнительными полями
```
A: ID | B: Чертеж | C: Описание | D: Кол-во | E: Заказчик | F: Срок | G-N: Операции
```

## 🔍 API Reference

### Анализ структуры файла
```http
POST /api/orders/analyze-excel
Content-Type: multipart/form-data

{
  "file": <Excel файл>
}
```

**Ответ:**
```json
{
  "fileName": "orders.xlsx",
  "sheets": [
    {
      "sheetName": "Заказы",
      "sheetIndex": 0,
      "rowCount": 150,
      "columnCount": 12,
      "columns": [
        {
          "columnIndex": 1,
          "columnLetter": "A",
          "header": "Номер чертежа",
          "sampleValues": ["DWG-001", "DWG-002"],
          "detectedType": "text",
          "suggestedMapping": "drawingNumber",
          "confidence": 85
        }
      ]
    }
  ],
  "recommendedSheet": 0,
  "availableMappings": ["drawingNumber", "quantity", "deadline", "priority", "workType", "operations"]
}
```

### Импорт с маппингом
```http
POST /api/orders/import-excel-with-mapping
Content-Type: multipart/form-data

{
  "file": <Excel файл>,
  "settings": <JSON строка с настройками>
}
```

**Настройки:**
```json
{
  "sheetIndex": 0,
  "hasHeaders": true,
  "startRow": 2,
  "columnMapping": {
    "drawingNumber": 1,
    "quantity": 2,
    "deadline": 3,
    "priority": 4,
    "workType": 5,
    "operations": {
      "startColumn": 6,
      "columnsPerOperation": 4,
      "maxOperations": 5
    }
  },
  "colorFilters": []
}
```

## 🐛 Решение проблем

### Файл не анализируется
- Убедитесь, что файл имеет расширение .xlsx или .xls
- Проверьте, что файл не поврежден
- Убедитесь, что размер файла не превышает ограничение

### Неправильные предложения соответствий
- Система анализирует первые несколько строк данных
- Убедитесь, что в этих строках есть репрезентативные данные
- При необходимости настройте соответствия вручную

### Ошибки импорта
- Проверьте, что указана колонка с номером чертежа (обязательное поле)
- Убедитесь, что форматы данных соответствуют ожиданиям
- Проверьте логи сервера для детальной диагностики
