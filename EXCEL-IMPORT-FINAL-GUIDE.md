### 📋 КАК РАБОТАЕТ EXCEL IMPORT С БД:

#### Шаг 1: Загрузка файла
- Пользователь загружает Excel файл через интерфейс
- Файл сохраняется физически в `backend/uploads/excel/`
- Создается запись в таблице `excel_imports`

#### Шаг 2: Парсинг и сохранение в БД
- Excel файл парсится по ячейкам
- **КАЖДАЯ ячейка** сохраняется в таблицу `excel_data`
- Запись включает: `importId`, `sheetName`, `rowNumber`, `columnName`, `cellValue`, `dataType`

#### Шаг 3: Маппинг колонок
- Применяется фильтр для маппинга названий колонок
- Русские заголовки: "Номер чертежа" → `drawing_number`
- Английские заголовки: "Drawing Number" → `drawing_number`

#### Шаг 4: Импорт в целевую таблицу
- Данные импортируются в таблицу `orders`
- Существующие заказы обновляются по `drawingNumber`
- Новые заказы создаются

#### Шаг 5: Результат и история
- Статус импорта обновляется в `excel_imports`
- Пользователь видит отчет: создано/обновлено/пропущено/ошибки
- Вся история сохраняется в БД для повторного использования

### 🗄️ СТРУКТУРА БД:

```sql
-- Таблица импортов
excel_imports (
  id, filename, original_filename, file_path, file_size,
  status, headers_count, rows_count, imported_to_orders,
  created_at, processed_date, error_message
)

-- Таблица ячеек Excel
excel_data (
  id, excel_import_id, sheet_name, row_number, 
  column_name, cell_value, data_type, created_at
)

-- Таблица фильтров
import_filters (
  id, name, description, target_table, 
  filter_config, column_mapping, is_active
)
```
