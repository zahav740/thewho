## 🔧 API ENDPOINTS ДОСТУПНЫ:

- `GET /api/excel-import-db/imports` - список импортов
- `GET /api/excel-import-db/filters` - список фильтров
- `POST /api/excel-import-db/upload` - загрузка Excel файла
- `GET /api/excel-import-db/imports/:id` - детали импорта

## 🎮 ИСПОЛЬЗОВАНИЕ В ИНТЕРФЕЙСЕ:

1. Откройте раздел "База данных"
2. Нажмите кнопку "🗄️ Excel БД Менеджер"
3. Выберите целевую таблицу (orders)
4. Выберите фильтр "Стандартный импорт заказов"
5. Перетащите Excel файл в область загрузки
6. Файл автоматически обработается и сохранится в БД
7. Данные импортируются в таблицу orders

## 📊 ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ КОЛОНОК:

### Русские названия:
- "Номер чертежа" или "Чертеж" → drawing_number
- "Количество" или "Кол-во" → quantity  
- "Срок" или "Дата" → deadline
- "Приоритет" → priority
- "Тип работы" → workType

### Английские названия:
- "Drawing Number" или "Part Number" → drawing_number
- "Quantity" или "Qty" → quantity
- "Deadline" или "Due Date" → deadline
- "Priority" → priority
- "Work Type" → workType
