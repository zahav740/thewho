# Модуль Excel Import - Инструкция по использованию

## Обзор

Создан полнофункциональный модуль для загрузки и управления Excel файлами с сохранением в базу данных. Модуль позволяет загружать Excel файлы, автоматически парсить их содержимое и предоставлять удобный интерфейс для работы с данными.

## Что было создано

### Backend (Node.js + NestJS + TypeORM)

1. **Сущность `ExcelFile`** (`src/database/entities/excel-file.entity.ts`)
   - Хранение Excel файлов в БД с метаданными
   - Поддержка дедупликации по MD5 хешу
   - Статусы обработки файлов
   - JSON хранение заголовков и данных

2. **Сервис `ExcelImportService`** (`src/modules/excel-import/excel-import.service.ts`)
   - Загрузка и парсинг Excel файлов
   - Валидация файлов
   - Повторная обработка с новыми параметрами
   - Статистика по файлам

3. **Контроллер `ExcelImportController`** (`src/modules/excel-import/excel-import.controller.ts`)
   - REST API для работы с Excel файлами
   - Swagger документация
   - Пагинация и фильтрация

4. **Миграция базы данных** (`src/database/migrations/1720007400000-CreateExcelFilesTable.ts`)
   - Создание таблицы `excel_files`
   - Индексы для оптимизации запросов

### Frontend (React + Ant Design)

1. **Компонент `ExcelImportManager`** (`src/components/ExcelImportManager/ExcelImportManager.tsx`)
   - Drag & Drop загрузка файлов
   - Таблица со списком файлов
   - Просмотр данных файлов
   - Статистика и фильтрация

2. **Страница `ExcelImportPage`** (`src/pages/ExcelImport/ExcelImportPage.tsx`)
   - Интеграция с общим Layout
   - Breadcrumbs навигация

3. **Маршрутизация**
   - Добавлен маршрут `/excel-import`
   - Пункт меню в Layout

## API Endpoints

### `POST /api/excel-import/upload`
Загрузка Excel файла
- **Параметры**: `file`, `description`, `maxRows`, `sheetIndex`, `skipEmptyRows`
- **Ответ**: Информация о загруженном файле

### `GET /api/excel-import/files`
Список всех файлов
- **Параметры**: `page`, `limit`, `status`
- **Ответ**: Пагинированный список файлов

### `GET /api/excel-import/files/:id/data`
Данные конкретного файла
- **Параметры**: `offset`, `limit`
- **Ответ**: Данные файла с пагинацией

### `DELETE /api/excel-import/files/:id`
Удаление файла

### `POST /api/excel-import/files/:id/reparse`
Повторная обработка файла

### `GET /api/excel-import/stats`
Статистика по файлам

## Использование

### 1. Запуск миграции
```bash
cd backend
npm run migration:run
```

### 2. Запуск backend
```bash
cd backend
npm run start:dev
```

### 3. Запуск frontend
```bash
cd frontend
npm start
```

### 4. Доступ к модулю
Откройте браузер и перейдите на `http://localhost:5101/excel-import`

## Ограничения

- Максимальный размер файла: 50MB
- Поддерживаемые форматы: .xlsx, .xls
- Максимальное количество строк для обработки: 10,000 (настраивается)
- Максимальное количество колонок: 100

## Конфигурация

Параметры загрузки можно настроить в:

- Frontend: `ExcelImportManager.tsx` - параметры компонента Upload
