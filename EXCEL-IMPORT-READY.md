## 📋 Как использовать

### 1. Доступ к системе импорта:
```
База данных → 🗄️ Excel БД Менеджер
```

### 2. Настройка фильтров:
```
База данных → ⚙️ Фильтры
```

### 3. Процесс импорта Excel:
1. Выберите целевую таблицу (Заказы/Операции)
2. Выберите фильтр импорта (опционально)  
3. Перетащите Excel файл в область загрузки
4. Дождитесь завершения обработки
5. Просмотрите результаты импорта

### 4. Управление фильтрами:
1. Создайте новый фильтр или отредактируйте существующий
2. Настройте JSON конфигурацию валидации
3. Настройте маппинг колонок Excel → БД
4. Сохраните и активируйте фильтр

## 🔧 API Endpoints

```
POST /api/excel-import-db/upload          # Загрузка Excel файла
GET  /api/excel-import-db/imports         # Список импортов  
GET  /api/excel-import-db/imports/:id     # Детали импорта
POST /api/excel-import-db/imports/:id/re-import  # Повторный импорт

GET  /api/excel-import-db/filters         # Список фильтров
POST /api/excel-import-db/filters         # Создание фильтра
PUT  /api/excel-import-db/filters/:id     # Обновление фильтра
DELETE /api/excel-import-db/filters/:id   # Удаление фильтра
```
