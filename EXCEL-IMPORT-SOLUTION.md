## 🚨 Проблема
Файл: `2025 june.xlsx`  
Лист: `תוכנית יצור` (Hebrew production plan)  
Ошибка: "Неверный формат даты" для всех 68 строк

## 🛠️ РЕШЕНИЯ

### Решение 1: Конверсия в CSV (РЕКОМЕНДУЕТСЯ)
1. **Откройте** ваш Excel файл `2025 june.xlsx`
2. **Выберите** лист `תוכנית יצור`
3. **Сохраните как** CSV (UTF-8): File → Save As → CSV (UTF-8)
4. **Используйте** CSV импорт в веб-интерфейсе

### Решение 2: Исправление формата даты в Excel
1. **Откройте** файл в Excel
2. **Найдите колонку** с датами дедлайнов
3. **Выделите колонку** и установите формат: `YYYY-MM-DD`
4. **Сохраните** файл
5. **Попробуйте** импорт снова

### Решение 3: Использование Production Plan Import
1. **Перейдите** на: http://localhost:5101/database
2. **Найдите** кнопку "Production Plan Import" 
3. **Используйте** специальный импорт для Hebrew файлов

### Решение 4: Гибкий импорт с маппингом колонок
1. **Используйте** "Flexible Import" в интерфейсе
2. **Настройте** соответствие колонок вручную
3. **Пропустите** проблемные колонки с датами
4. **Импортируйте** только основные данные
