5. Создание записи в `excel_imports` с метаданными
6. Валидация и импорт в целевую таблицу (orders/operations)
7. Обновление статуса импорта

## 🗃️ Структура базы данных

### Таблица `excel_imports`
Хранит метаданные о загруженных файлах:
- `id` - уникальный идентификатор
- `filename` - имя файла на сервере
- `original_filename` - оригинальное имя файла
- `status` - статус обработки (uploaded/processing/processed/error)
- `headers_count` - количество колонок
- `rows_count` - количество строк
- `imported_to_orders` - импортировано ли в заказы
- `imported_to_operations` - импортировано ли в операции

### Таблица `excel_data`
Хранит все ячейки из Excel файлов:
- `excel_import_id` - связь с импортом
- `sheet_name` - имя листа
- `row_number` - номер строки
- `column_name` - имя колонки
- `cell_value` - значение ячейки
- `data_type` - тип данных

### Таблица `import_filters`
Хранит настройки фильтров импорта:
- `name` - название фильтра
- `target_table` - целевая таблица
- `column_mapping` - соответствие колонок
- `filter_config` - конфигурация валидации

## 🔧 API Endpoints

### Анализ файла (без импорта)
```
POST /api/excel-import-db/analyze-excel
Content-Type: multipart/form-data
Body: file (Excel файл)
```

### Импорт файла в БД
```
POST /api/excel-import-db/upload?targetTable=orders&filterId=1
Content-Type: multipart/form-data  
Body: file (Excel файл)
```

### Получение списка импортов
```
GET /api/excel-import-db/imports?page=1&limit=20
```

### Получение деталей импорта
```
GET /api/excel-import-db/imports/:id
```

### Получение схемы таблицы БД
```
GET /api/excel-import-db/database-schema/:table
```

### Управление фильтрами
```
GET /api/excel-import-db/filters
POST /api/excel-import-db/filters
PUT /api/excel-import-db/filters/:id
DELETE /api/excel-import-db/filters/:id
```

## 📊 Поддерживаемые форматы и ограничения

### Форматы файлов
- ✅ .xlsx (Excel 2007+)
- ✅ .xls (Excel 97-2003)
- ❌ .csv (используйте отдельный CSV импорт)

### Ограничения
- Максимальный размер файла: 50MB
- Максимальное количество строк: 10,000
- Поддержка только первого листа Excel

### Типы данных
- **string** - текстовые данные
- **number** - числовые данные  
- **date** - даты
- **boolean** - логические значения

## 🔍 Диагностика и устранение неполадок

### Распространенные ошибки

**1. "HTTP error! status: 404"**
- Проверьте, что backend запущен на порту 5100
- Убедитесь, что маршруты /api/excel-import-db/* настроены

**2. "Файл не поддерживается"**  
- Проверьте расширение файла (.xlsx/.xls)
- Убедитесь, что файл не поврежден

**3. "Обязательные поля не найдены"**
- Проверьте наличие колонок с номерами чертежей и количеством
- Проверьте правильность названий колонок

### Проверка системы
Используйте скрипт `TEST-EXCEL-IMPORT-SYSTEM.bat` для проверки всех компонентов.
