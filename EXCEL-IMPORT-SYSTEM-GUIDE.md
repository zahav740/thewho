# Excel Import System - Руководство по использованию

## Обзор системы

Система импорта Excel файлов состоит из нескольких компонентов:

### 1. 🎯 Интерактивный маппер Excel (InteractiveColumnMapper)
**Назначение**: Простой и интуитивный способ импорта Excel файлов с визуальным выбором колонок

**Как использовать**:
1. Нажмите кнопку "🎯 Excel Маппер" в секции База данных
2. Выберите целевую таблицу (Заказы или Операции)
3. Загрузите Excel файл - система автоматически проанализирует структуру
4. Выберите какие колонки импортировать, используя чекбоксы
5. Сопоставьте колонки Excel с полями базы данных
6. Нажмите "Импортировать выбранные колонки"

**Особенности**:
- Автоматическое определение типов данных
- Показывает примеры данных из колонок
- Процентаж заполненности колонок
- Умное предложение соответствия полям БД
- Поддержка русского, английского и иврита

### 2. 📋 История импорта Excel (ExcelImportsList)
**Назначение**: Просмотр всех ранее загруженных Excel файлов

**Как использовать**:
1. Нажмите кнопку "📋 История импорта" в секции База данных
2. Просмотрите список всех импортов с их статусами
3. Нажмите "Детали" для просмотра подробной информации
4. Просмотрите превью данных и ошибки импорта

**Статусы импорта**:
- 🔵 Загружен - файл загружен, но не обработан
- 🟠 Обработка - файл в процессе обработки
- 🟢 Обработан - импорт успешно завершен
- 🔴 Ошибка - произошла ошибка при импорте

### 3. 🗼 Менеджер импорта (ExcelImportManagerAntd)
**Назначение**: Полный менеджер для управления всеми аспектами импорта

**Возможности**:
- Просмотр всех импортов
- Управление фильтрами
- Повторный импорт с другими настройками
- Детальная аналитика

### 4. ⚙️ Менеджер фильтров (FilterManagerAntd)
**Назначение**: Создание и управление фильтрами импорта

**Функции**:
- Создание новых фильтров
- Настройка маппинга колонок
- Валидация данных
- Активация/деактивация фильтров

## Backend API Endpoints

### Анализ Excel файла
```
POST /api/excel-import-db/analyze-excel
```
Анализирует структуру Excel файла без импорта

### Импорт Excel файла
```
POST /api/excel-import-db/upload?targetTable=orders&filterId=1
```
Импортирует Excel файл в указанную таблицу

### Список импортов
```
GET /api/excel-import-db/imports?page=1&limit=20
```
Получает список всех импортов с пагинацией

### Детали импорта
```
GET /api/excel-import-db/imports/:id
```
Получает детали конкретного импорта

### Схема базы данных
```
GET /api/excel-import-db/database-schema/orders
```
Получает схему таблицы для маппинга

## Поддерживаемые форматы

- ✅ .xlsx (Excel 2007+)
- ✅ .xls (Excel 97-2003)
- ✅ Максимальный размер файла: 50MB
- ✅ Максимальное количество строк: 10,000

## Маппинг колонок

### Для таблицы "orders" (заказы):
- **drawing_number** - Номер чертежа (обязательно)
- **quantity** - Количество (обязательно)  
- **deadline** - Срок выполнения
- **priority** - Приоритет (1-4)
- **workType** - Тип работы
- **customer** - Заказчик
- **order_number** - Номер заказа

### Автоматическое определение колонок:
Система умеет распознавать колонки на разных языках:

**Русский**: "Номер чертежа", "Количество", "Срок", "Приоритет"
**English**: "Drawing Number", "Quantity", "Deadline", "Priority"  
**עברית**: Поддержка иврита для локальных пользователей

## Безопасность и хранение

- Все файлы сохраняются в `backend/uploads/excel/`
- Данные из Excel сохраняются в таблице `excel_data`
- Метаданные импорта в таблице `excel_imports`
- Настройки фильтров в таблице `import_filters`

## Устранение неполадок

### Ошибка "Файл не поддерживается"
- Убедитесь, что файл имеет расширение .xlsx или .xls
- Проверьте, что файл не поврежден

### Ошибка "Обязательные поля не найдены"
- Убедитесь, что Excel файл содержит колонки с номерами чертежей и количеством
- Проверьте правильность названий колонок

### Импорт не создает заказы
- Проверьте, что выбрана правильная целевая таблица
- Убедитесь, что обязательные поля сопоставлены

## Рекомендации по использованию

1. **Начните с анализа**: Всегда используйте интерактивный маппер для нового типа файла
2. **Создайте фильтры**: Для часто используемых форматов создайте фильтры
3. **Проверяйте историю**: Регулярно просматривайте историю импорта на наличие ошибок
4. **Бэкап данных**: Делайте резервные копии перед массовым импортом

## Статистика использования

Система автоматически ведет статистику:
- Общее количество импортов
- Успешные/неуспешные импорты  
- Время обработки файлов
- Количество созданных/обновленных записей
