## 🔧 Основные возможности

### Excel Column Mapper (исправлено)
1. **Скрытие колонок**
   - Нажмите "Скрыть" у любой колонки
   - Колонка станет серой и будет исключена из импорта
   - Кнопка "Показать" вернет колонку обратно

2. **Редактирование заголовков**
   - Нажмите иконку карандаша у заголовка
   - Отредактируйте текст inline
   - Нажмите Enter или кнопку сохранения
   - Измененные заголовки выделяются синим цветом

3. **Защита данных**
   - Номер чертежа (обязательное поле) нельзя скрыть
   - Валидация настроек перед импортом
   - Автоматическая очистка при смене листа

### Excel Import API
- `POST /api/excel-import/upload` - загрузка файла
- `GET /api/excel-import/files` - список файлов
- `GET /api/excel-import/stats` - статистика
- `DELETE /api/excel-import/files/{id}` - удаление
