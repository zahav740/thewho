# 🚀 Инструкция по запуску системы "Заказы V2"

## 📋 Что было создано

### ✅ Frontend (React + TypeScript)
- **Новая страница**: `/src/pages/Orders/OrdersPage.tsx`
- **Компоненты**:
  - `OrdersList.tsx` - Умная таблица заказов с сортировкой по приоритетам
  - `OrderForm.tsx` - Форма с автоматическим расчетом приоритетов
  - `ExcelImportModal.tsx` - Стабильный импорт Excel с пошаговым процессом
- **Стили**: `OrdersPage.css` - Адаптивный дизайн
- **Интеграция**: Добавлено в главное меню и маршрутизацию

### ✅ Backend (NestJS + TypeORM)
- **Новые API**: `/src/modules/orders/v2/`
  - `OrdersV2Controller` - REST API endpoints
  - `OrdersV2Service` - Бизнес-логика с умными приоритетами
  - `PriorityCalculatorService` - Автоматический расчет приоритетов
  - `ExcelParserService` - Парсинг Excel файлов
- **Модуль**: `OrdersV2Module` - Интегрирован в главный модуль
- **Enums**: Приоритеты и типы операций для V2

### ✅ Интеллектуальная система приоритетов
- **Алгоритм расчета**: Срочность (60%) + Сложность (40%)
- **Факторы**:
  - Дедлайн (просрочено = 100 баллов)
  - Тип работы (сложные операции = больше баллов)
  - Количество (большие партии = больше баллов)
  - Операции (4-осевые, длительные = больше баллов)

## 🎯 Ключевые особенности

### 1. Дефолтные колонки Excel (согласно ТЗ)
- **Колонка C**: Номер чертежа
- **Колонка E**: Количество
- **Колонка G**: Дедлайн
- **Колонка K**: Приоритет (опционально)

### 2. Умная сортировка
- Заказы автоматически сортируются по приоритету и дедлайну
- Позиции 1-3: Красные (критичные)
- Позиции 4-10: Оранжевые (важные)
- Остальные: Зеленые (стандартные)

### 3. Пошаговый Excel импорт
1. Загрузка файла
2. Автоматический парсинг
3. Предварительный просмотр с расчетом приоритетов
4. Сохранение в БД

## 📊 API Endpoints

### Основные операции
- `GET /api/v2/orders` - Список заказов с умными приоритетами
- `POST /api/v2/orders` - Создание заказа
- `PUT /api/v2/orders/:id` - Обновление заказа
- `DELETE /api/v2/orders/:id` - Удаление заказа

### Excel операции
- `POST /api/v2/orders/parse-excel` - Парсинг Excel файла
- `POST /api/v2/orders/import-from-excel` - Импорт из Excel
- `POST /api/v2/orders/batch` - Массовое создание

### Управление приоритетами
- `GET /api/v2/orders/stats` - Статистика
- `POST /api/v2/orders/recalculate-priorities` - Пересчет приоритетов

## 🔧 Устранение проблем

### Проблема: Backend не запускается
```bash
# Проверьте зависимости
cd backend
npm install
npm audit fix

# Проверьте порты
netstat -ano | findstr :5100
```

### Проблема: Frontend не подключается к API
```bash
# Проверьте файл .env в frontend
echo "REACT_APP_API_URL=http://localhost:5100/api" > .env

# Перезапустите frontend
npm start
```

### Проблема: Excel импорт не работает
1. Убедитесь, что файл имеет правильную структуру
2. Проверьте права на папку `backend/uploads/excel`
3. Убедитесь, что размер файла не превышает 10MB
