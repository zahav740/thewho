## 🛠️ Если что-то не работает

### Проблема: Порт занят
```bash
# Освободить порты
netstat -ano | findstr ":5100 :5101"
# Найти PID процесса и завершить его
taskkill /PID [номер_процесса] /F
```

### Проблема: API недоступен
```bash
# Проверить backend
curl http://localhost:5100/api/health
# Или открыть в браузере
```

### Проблема: Frontend не подключается
```bash
# Проверить .env файл
cat frontend/.env
# Должен содержать: REACT_APP_API_URL=http://localhost:5100/api
```
