1. ❌ **Ошибка 500** при запросе PDF файлов

## ✅ Что было исправлено

### 🔧 Backend исправления

#### Новые файлы:
- `pdf-fixed.controller.ts` - Исправленный контроллер PDF
- `orders-pdf-fixed.controller.ts` - Главный контроллер заказов с PDF
- `pdf-system-cleanup.sql` - SQL скрипт для очистки и подготовки БД

#### Новая архитектура файлов:
```
uploads/pdf/
├── E-25142-000-266000/           # Папка номера чертежа
│   ├── E25142A-2_2D_VIEW.pdf     # Основной файл
│   └── E25142A-2_2D_VIEW_rev2.pdf # Ревизия
├── DWG-98765/
│   └── assembly.pdf
└── PART-54321/
    ├── main.pdf
    └── details.pdf
```

#### Исправленные API endpoints:
```javascript
// Новые endpoints с правильной обработкой
GET    /api/orders/pdf/{drawingNumber}/{filename}   // Получить PDF
POST   /api/orders/{orderId}/upload-pdf             // Загрузить с проверкой дубликатов  
DELETE /api/orders/{orderId}/pdf                    // Удалить PDF
GET    /api/orders/{orderId}/pdf/info               // Информация о PDF
GET    /api/orders/drawing/{drawingNumber}/pdfs     // Все PDF для чертежа
GET    /api/orders/pdf/statistics                   // Статистика
POST   /api/orders/pdf/cleanup                      // Очистка устаревших файлов
```

### 🎨 Frontend исправления

#### Новые файлы:
- `pdfApi.fixed.ts` - Исправленный API клиент
- `OrderForm.FIXED.tsx` - Исправленная форма заказов
- `InlinePdfViewer.FIXED.tsx` - Исправленный просмотрщик PDF

#### Новые возможности UI:
- ✅ **Drag & Drop** интерфейс для загрузки PDF
- ✅ **Модальное окно обработки дубликатов** с выбором действий
- ✅ **Множественные режимы просмотра** PDF (iframe, object, embed, ссылки)
- ✅ **Диагностическая панель** с информацией о статусе загрузки
- ✅ **Превью PDF** прямо в форме заказа
- ✅ **Статус индикаторы** загрузки и ошибок

### 🔍 Система обработки дубликатов

#### Проверка дубликатов по:
1. **MD5 хеш файла** - обнаруживает идентичные файлы
2. **Номер чертежа** - находит уже загруженные файлы для того же чертежа
3. **Имя файла** - предотвращает перезапись с тем же именем

#### Действия при обнаружении дубликата:
1. 🔄 **Перезаписать** - заменить существующий файл новым
2. 🔗 **Использовать существующий** - связать заказ с уже загруженным файлом
3. 📋 **Создать ревизию** - сохранить как новую версию (v2, v3, ...)
4. ⚡ **Принудительно загрузить** - игнорировать дубликат и загрузить в любом случае

## 📊 База данных

### Новые SQL функции:
```sql

SELECT * FROM get_pdf_statistics();

-- Очистить устаревшие записи
SELECT * FROM cleanup_orphaned_pdf_records();

-- Просмотреть информацию о всех PDF
SELECT * FROM pdf_files_info LIMIT 10;

-- Проверить валидность путей
SELECT * FROM orders WHERE pdf_path IS NOT NULL AND NOT is_valid_pdf_path(pdf_path);
```
