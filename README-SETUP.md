# TheWho CRM - Инструкция по настройке

## 🚀 Быстрый старт

### 1. Настройка базы данных

Убедитесь, что PostgreSQL запущен:
- База данных: `thewho`
- Пользователь: `postgres`
- Пароль: `magarel`
- Порт: `5432`

### 2. Установка зависимостей

```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

### 3. Файлы окружения

Файлы `.env` уже созданы для локальной разработки:
- `/.env` - корневые настройки
- `/backend/.env` - настройки бэкенда
- `/frontend/.env` - настройки фронтенда

### 4. Запуск приложения

#### Через корневой скрипт:
```bash
.\START-CRM-ENGLISH-FIXED.bat
```

#### Или раздельно:

**Backend (порт 5100):**
```bash
cd backend
npm start
```

**Frontend (порт 5101):**
```bash
cd frontend
npm start
```

## 📁 Структура .env файлов

### Корневой `.env`
- Общие настройки приложения
- Настройки базы данных
- JWT конфигурация

### Backend `.env`
- Настройки сервера бэкенда
- Подключение к БД
- Файловые загрузки

### Frontend `.env`
- URL API бэкенда
- Настройки разработки
- Порт фронтенда

## 🔒 Безопасность

Все `.env` файлы добавлены в `.gitignore` и не попадут в Git:
- `.env`
- `.env.*`
- `backend/.env`
- `frontend/.env`
- И многие другие варианты

## 🌐 URL приложения

После запуска:
- **Frontend**: http://localhost:5101
- **Backend API**: http://localhost:5100/api

## 🔧 Troubleshooting

### Ошибка подключения к БД
1. Проверьте, что PostgreSQL запущен
2. Убедитесь, что база данных `thewho` существует
3. Проверьте пароль в `.env` файлах

### Порты уже заняты
Измените порты в соответствующих `.env` файлах:
- `PORT=5100` (backend)
- `PORT=5101` (frontend)

### Ошибки npm install
```bash
npm audit fix
npm audit fix --force  # если нужно
```

## 📝 Примечания

- Используйте `.env.example` как шаблон для создания новых конфигураций
- Никогда не коммитьте реальные `.env` файлы с паролями
- Для продакшена используйте `.env.prod` или `.env.beget`
