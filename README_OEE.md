## 📊 Формулы OEE и KPI

### 🎯 OEE (Overall Equipment Effectiveness):
```
OEE = Доступность × Производительность × Качество / 10000

Где:
- Доступность = (Смена - Простои) / Смена × 100%
- Производительность = Факт деталей / План деталей × 100%  
- Качество = (Факт - Брак) / Факт × 100%
```

### 📈 KPI (Key Performance Indicator):
```
KPI = OEE×50% + (100-Доля_наладки)×20% + Качество_наладки×15% + Сроки×15%

Где:
- Доля_наладки = Время_наладки / Смена × 100%
- Качество_наладки = (Факт - Брак) / Факт × 100%
- Сроки = 90% (константа, можно заменить на реальные данные)
```

## 🎨 Цветовые индикаторы

### OEE:
- 🟢 **Зеленый**: ≥ 80% (отличный результат)
- 🟡 **Желтый**: 70-79% (хороший результат)
- 🔴 **Красный**: < 70% (требует улучшения)

### KPI:
- 🟢 **Зеленый**: ≥ 85% (цель достигнута)
- 🟡 **Желтый**: 75-84% (близко к цели)
- 🔴 **Красный**: < 75% (требует внимания)
