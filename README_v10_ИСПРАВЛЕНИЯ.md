## 📊 ФОРМУЛЫ

### Остаток производства:
```excel
=IFERROR(MAX(0,F{prev_row}-I{prev_row}+J{prev_row}),F{prev_row})
```

### OEE:
```excel
=IFERROR(L{row}*M{row}*N{row}/10000,0)
```

### KPI:
```excel
=IFERROR(O{row}*0.5+(100-(E{row}/D{row}*100))*0.2+N{row}*0.15+90*0.15,0)
```
