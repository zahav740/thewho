# 🚀 Инструкция по запуску исправленной системы

## 🎯 Что исправлено

✅ **Критическая проблема**: Обнуление операций при импорте дубликатов Excel  
✅ **Soft Delete**: Заказы не удаляются из БД, остаются для проверки дубликатов  
✅ **Выбор действий**: Полный контроль пользователя над дубликатами  
✅ **Умное обновление**: Сохранение прогресса выполненных операций

## 🎮 Как использовать новый функционал

### 🔄 Импорт Excel с проверкой дубликатов

1. Откройте страницу **"База данных"**
2. Нажмите кнопку **"🔄 Excel (проверка дубликатов)"**
3. Выберите один из режимов:

#### 🔍 Режим с анализом дубликатов
- Загрузите файл для детального анализа
- Система покажет все найденные дубликаты
- Выберите действие для каждого дубликата:
  - ✅ **Умное обновление** - обновляет данные, сохраняет прогресс (рекомендуется)
  - ⚠️ **Полная замена** - сбрасывает ВСЁ (только если уверены!)
  - 🔄 **Объединение** - умное слияние данных
  - 🔄 **Восстановление** - для удаленных заказов
  - ⏭️ **Пропустить** - оставить как есть

#### ⚡ Автоматический режим
- Выберите действие для всех дубликатов:
  - **Пропускать дубликаты** (безопасно)
  - **Заменять дубликаты** (умное обновление)
- Загрузите файл для мгновенного импорта

### 🗑️ Работа с удаленными заказами

- **Удаление**: Заказы помечаются как удаленные, но остаются в БД
- **Просмотр**: `GET /api/orders/deleted/list` 
- **Восстановление**: `POST /api/orders/:id/restore`

## 🛡️ Безопасность данных

### ✅ Что защищено:
- **Выполненные операции** - никогда не удаляются при обновлении
- **Операции в процессе** - сохраняются при умном обновлении  
- **История заказов** - мягкое удаление сохраняет все данные
- **Проверка дубликатов** - включает удаленные записи

### ⚠️ Предупреждения в интерфейсе:
- Система предупреждает о выполненных операциях
- Показывает различия между заказами
- Четко указывает какие данные будут затронуты

## 🔍 Диагностика проблем

### Если не запускается backend:

1. **Проверьте применение миграции:**
```sql
-- В PostgreSQL выполните:
\d orders
-- Должны быть видны новые колонки: isDeleted, deletedAt, deletedBy
```

2. **Проверьте логи:**
```bash
cd backend
npm run start:dev
# Смотрите на ошибки в консоли
```

3. **Проверьте переменные окружения:**
```bash
# В файле backend/.env должны быть:
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_NAME=your_db_name
DATABASE_USERNAME=your_username
DATABASE_PASSWORD=your_password
```

### Если не видна кнопка дубликатов в интерфейсе:

1. **Проверьте что frontend обновлен:**
```bash
cd frontend
npm install
npm start
```

2. **Очистите кеш браузера** (Ctrl+F5)

3. **Проверьте что компоненты созданы:**
- `frontend/src/components/ExcelImportManager/DuplicateResolutionModal.tsx`
- `frontend/src/components/ExcelImportManager/EnhancedExcelImportModal.tsx`

## 📊 API эндпоинты для дубликатов

### Анализ дубликатов:
```
POST /api/excel-import-duplicates/analyze
Content-Type: multipart/form-data
Body: file (Excel файл)
```

### Обработка решений:
```
POST /api/excel-import-duplicates/process-with-resolutions
Content-Type: application/json
Body: {
  fileId: "...",
  resolutions: {
    resolutions: [
      {
        orderDrawingNumber: "ORDER123",
        action: "replace"
      }
    ],
    defaultAction: "skip"
  }
}
```

### Автоматический импорт:
```
POST /api/excel-import-duplicates/import-auto
Content-Type: multipart/form-data
Body: 
  file (Excel файл)
  autoAction: "skip" | "replace"
```
