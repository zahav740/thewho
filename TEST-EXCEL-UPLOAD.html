🔧 Тест загрузки Excel файлов

Используйте эту страницу для тестирования загрузки и обработки Excel файлов в системе.

📋 Тест 1: Проверка файла

Проверяет структуру Excel файла без импорта данных

📁 Кликните или перетащите Excel файл сюда

Поддерживаются форматы: .xlsx, .xls

Выберите файл для проверки

🚀 Тест 2: Полный импорт

Полная загрузка и импорт данных из Excel в базу данных

📁 Кликните или перетащите Excel файл сюда

Файл будет импортирован в базу данных

Выберите файл для импорта

🧪 Тест 3: Тестовый режим

Имитация импорта без реального сохранения в базу данных

📁 Кликните или перетащите Excel файл сюда

Только тестирование, данные не сохраняются

Выберите файл для тестирования
