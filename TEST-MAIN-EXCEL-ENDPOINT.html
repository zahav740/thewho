🎯 Тест основного Excel endpoint

Этот тестер проверяет конкретно endpoint /api/orders/upload-excel, который используется фронтендом.

🔗 Тестируемый endpoint:
POST /api/orders/upload-excel
📝 Поле файла: excel
🎨 Цветовые фильтры: colorFilters (JSON string)

📂 Загрузка Excel файла

📊

Перетащите Excel файл сюда или кликните для выбора

Поддерживаются форматы: .xlsx, .xls

Максимальный размер: 100MB

Выберите Excel файл для загрузки

📋 Инструкции

  1. Выберите Excel файл с данными заказов
  2. Нажмите "Загрузить Excel" для отправки на сервер
  3. Проверьте результат в области ниже
