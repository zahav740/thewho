## 🧪 Диагностика

Тест подключения проверит 3 варианта:
1. **DATABASE_URL** - прямое подключение через строку
2. **Параметры** - подключение через отдельные параметры (порт 6543)
3. **Session mode** - подключение через порт 5432

## 🔧 Если проблемы остаются

1. **Запустите UPDATE-DEPENDENCIES.bat** для обновления pg драйвера
2. **Проверьте подключение** через TEST-SUPABASE-CONNECTION.bat
3. **Убедитесь что Supabase проект активен** в панели управления
4. **Проверьте IP whitelist** в Supabase (или отключите ограничения)
5. **Попробуйте сбросить пароль** базы данных в Supabase
6. **Проверьте файрвол** - порты 5432 и 6543 должны быть открыты
