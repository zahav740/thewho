# 📁 Структура файлов и директорий

## Места сохранения файлов в приложении

### 📄 **PDF файлы**
**Путь:** `uploads/pdf/`
- Загруженные PDF чертежи заказов
- Ревизии PDF файлов (с префиксом `-rev{номер}`)
- Временные файлы при загрузке

### 📋 **Данные заказов (файловая система)**
**Путь:** `uploads/orders/`
- Структурированное хранение заказов по номерам чертежей
- Версионное управление изменениями заказов
- JSON файлы с операциями, планированием, сменами

#### Структура папки заказов:
```
uploads/orders/
├── DRW-2024-001/              # Номер чертежа
│   ├── 2025-06-24/            # Версия (дата создания)
│   │   ├── order.json         # Основные данные заказа
│   │   ├── metadata.json      # Метаданные версии
│   │   ├── operations/        # Операции
│   │   │   └── operations.json
│   │   ├── shifts/            # Данные смен
│   │   │   └── shifts_records.json
│   │   ├── planning/          # Планирование
│   │   │   └── planning_results.json
│   │   ├── documents/         # Документы
│   │   ├── history/           # История изменений
│   │   ├── exports/           # Экспорты
│   │   └── analysis/          # Аналитика
│   ├── 2025-06-24_14-30/     # Обновленная версия
│   └── latest_version.json    # Указатель на последнюю версию
└── DRW-2024-002/              # Другой заказ
    └── ...
```

### 🗄️ **База данных**
- Основные данные заказов и операций
- Связи между заказами и файлами
- Хеши файлов для предотвращения дубликатов

## Автоматическое создание директорий

При запуске приложения автоматически создаются:
- `uploads/pdf/` - для PDF файлов
- `uploads/orders/` - для данных заказов

## Логи

Все операции с файлами логируются в консоль приложения:
- Создание директорий
- Сохранение заказов
- Загрузка PDF
- Ошибки доступа к файлам

## Конфигурация

Пути можно изменить через переменные окружения:
- `UPLOAD_DIR` - базовая директория для загрузок (по умолчанию: `uploads/pdf`)
- Директория заказов всегда относительно `process.cwd() + '/uploads/orders'`
