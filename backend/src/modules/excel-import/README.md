# Excel Import Module - Улучшенная версия

## 📋 Описание

Улучшенный модуль для загрузки, обработки и управления Excel файлами в базе данных. Исправлены проблемы с загрузкой файлов и добавлены новые возможности.

## 🔧 Улучшения

### ✅ Исправленные проблемы:
- **Проблемы с загрузкой файлов** - улучшена обработка различных типов Excel файлов
- **Ошибки парсинга** - добавлена надежная обработка различных типов ячеек
- **Проблемы с валидацией** - улучшена валидация файлов перед загрузкой
- **Отсутствие предпросмотра** - добавлен предпросмотр данных при загрузке

### 🆕 Новые возможности:
- **Валидация файлов** - проверка файлов перед загрузкой
- **Предпросмотр данных** - показ первых 5 строк при загрузке
- **Поиск файлов** - поиск по названию файла или описанию
- **Массовое удаление** - удаление нескольких файлов одновременно
- **Экспорт в JSON** - экспорт данных в формате JSON
- **Подробная статистика** - детальная статистика по файлам
- **Улучшенная обработка ошибок** - более информативные сообщения об ошибках

## 📊 API Endpoints

### 🔍 Валидация файла
```
POST /api/excel-import/validate
```
Проверяет файл на корректность без загрузки в БД.

### 📤 Загрузка файла
```
POST /api/excel-import/upload
```
Загружает Excel файл и автоматически парсит содержимое.

Параметры:
- `file` - Excel файл (.xlsx, .xls)
- `description` - описание файла
- `uploadedBy` - кто загрузил файл
- `maxRows` - максимальное количество строк для обработки
- `sheetIndex` - индекс листа для обработки (0-based)
- `skipEmptyRows` - пропускать пустые строки
- `headerRow` - номер строки с заголовками (по умолчанию 1)

### 📋 Список файлов
```
GET /api/excel-import/files?page=1&limit=20&status=parsed&search=данные
```
Возвращает список загруженных файлов с фильтрацией.

### 📊 Данные файла
```
GET /api/excel-import/files/{id}/data?offset=0&limit=100
```
Возвращает данные файла с пагинацией.

### 🔄 Повторная обработка
```
POST /api/excel-import/files/{id}/reparse
```
Перепарсивает файл с новыми параметрами.

### 📈 Статистика
```
GET /api/excel-import/stats
```
Возвращает статистику по всем файлам.

### 🗑️ Удаление файлов
```
DELETE /api/excel-import/files/{id}
DELETE /api/excel-import/files/bulk
```
Удаление одного файла или массовое удаление.

### 💾 Скачивание и экспорт
```
GET /api/excel-import/files/{id}/download
GET /api/excel-import/files/{id}/export-json
```
Скачивание оригинального файла или экспорт в JSON.

## 🛠️ Конфигурация

### Параметры в коде:
- **Максимальный размер файла**: 50MB
- **Максимальное количество строк**: 10,000 (по умолчанию)
- **Максимальное количество колонок**: 100
- **Директория загрузки**: `uploads/excel/`

### Поддерживаемые форматы:
- `.xlsx` - Excel 2007+
- `.xls` - Excel 97-2003
- `.csv` - CSV файлы (частично)

## 📄 Структура данных

### ExcelFile Entity
```typescript
{
  id: number;
  originalName: string;
  description: string;
  fileSize: number;
  mimeType: string;
  fileHash: string;
  fileData: Buffer;
  headers: string[];
  parsedData: string; // JSON
  rowsCount: number;
  sheetsCount: number;
  status: 'uploading' | 'parsed' | 'error' | 'processing';
  errorMessage: string;
  uploadedBy: string;
  metadata: any;
  createdAt: Date;
  updatedAt: Date;
}
```

### Статусы файлов:
- `uploading` - файл загружается
- `processing` - файл обрабатывается
- `parsed` - файл успешно обработан
- `error` - ошибка при обработке

## 🔧 Обработка ошибок

### Типы ошибок:
1. **Валидация файла** - неподдерживаемый формат, слишком большой размер
2. **Парсинг данных** - некорректная структура Excel файла
3. **База данных** - ошибки при сохранении
4. **Система** - нехватка памяти, дискового пространства

### Логирование:
Все операции логируются с подробными сообщениями:
- `🔥` - начало загрузки
- `💾` - сохранение в БД
- `✅` - успешное завершение
- `❌` - ошибки
- `⚠️` - предупреждения
