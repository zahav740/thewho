# 🔧 Исправление проблемы парсинга Excel

## 🚨 Проблема
Ошибка: **"Can't read the data of 'the loaded zip file'. Is it in a supported JavaScript type (String, Blob, ArrayBuffer, etc) ?"**

## 🔍 Причина
- Контроллер сохранял файлы на диск с `multer.diskStorage()`
- Но сервис парсинга ожидал `file.buffer` в памяти
- Из-за этого `file.buffer` был `undefined`

## ✅ Исправления

### 1. В серверном контроллере (`orders-v2.controller.ts`):
```typescript
// Было (неправильно):
storage: multer.diskStorage({
  destination: './uploads/excel',
  filename: (req, file, cb) => { ... }
})

// Стало (правильно):
storage: multer.memoryStorage() // Файл остается в памяти как Buffer
```

### 2. В клиентском коде (`ExcelImportModal.tsx`):
- Убрали неправильный `Content-Type: 'multipart/form-data'`
- Добавили таймаут 30 секунд для больших файлов
- Улучшили обработку ошибок и логирование

### 3. Добавлено подробное логирование:
- Информация о файле (размер, тип, наличие buffer)
- Проверки на стороне сервера
- Детальная диагностика ошибок

## 🎯 Теперь система должна работать:
- ✅ Файл корректно передается как Buffer
- ✅ ExcelJS может прочитать zip-данные
- ✅ Подробные логи для диагностики
- ✅ Правильная обработка ошибок
