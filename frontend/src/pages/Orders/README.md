# Заказы V2 - Улучшенная версия

## Обзор

Новая секция "Заказы" является улучшенной версией существующей секции "База данных" с следующими ключевыми улучшениями:

### 1. Интеллектуальная система приоритетов
- **Автоматический расчет приоритетов** на основе дедлайнов и сложности операций
- **Умное распределение** заказов по важности
- **Динамическое обновление** приоритетов при изменении условий

### 2. Улучшенная загрузка Excel
- **Стабильная работа** с Excel файлами любого размера

- **Автоматическое определение** типов данных
- **Пошаговый процесс** импорта с предварительным просмотром

### 3. Умная сортировка и отображение
- **Приоритетная сортировка** заказов
- **Цветовая индикация** срочности
- **Позиционная нумерация** для понимания очередности
- **Детальная статистика** по приоритетам

### 4. Расширенная аналитика
- **Статистика по приоритетам** (высокий, средний, низкий)
- **Анализ просроченных заказов**
- **Метрики сложности операций**
- **Прогнозирование загрузки**

## 📊 Система приоритетов

### Алгоритм расчета
1. **Срочность** (60% веса):
   - Просрочено: 100 баллов
   - До 1 дня: 95 баллов
   - До 3 дней: 85 баллов
   - До 7 дней: 70 баллов
   - До 14 дней: 50 баллов
   - До 30 дней: 30 баллов
   - Более 30 дней: 10 баллов

2. **Сложность** (40% веса):
   - Тип работы: до 40 баллов
   - Количество: до 30 баллов
   - Операции: до 50 баллов

3. **Итоговый приоритет**:
   - 75+ баллов: Высокий
   - 40-74 балла: Средний
   - 0-39 баллов: Низкий

## 🔧 Дефолтные колонки Excel

Согласно ТЗ, система автоматически обрабатывает следующие колонки:
- **Колонка C**: Номер чертежа
- **Колонка E**: Количество
- **Колонка G**: Дедлайн
- **Колонка K**: Приоритет (опционально)

## 📋 API Endpoints

### Основные операции
- `GET /api/v2/orders` - Получить все заказы с умными приоритетами
- `GET /api/v2/orders/:id` - Получить заказ по ID
- `POST /api/v2/orders` - Создать новый заказ
- `PUT /api/v2/orders/:id` - Обновить заказ
- `DELETE /api/v2/orders/:id` - Удалить заказ

### Excel операции
- `POST /api/v2/orders/parse-excel` - Парсинг Excel файла
- `POST /api/v2/orders/import-from-excel` - Импорт заказов из Excel
- `POST /api/v2/orders/batch` - Массовое создание заказов

### Управление приоритетами
- `GET /api/v2/orders/stats` - Получить статистику заказов
- `POST /api/v2/orders/recalculate-priorities` - Пересчитать приоритеты
