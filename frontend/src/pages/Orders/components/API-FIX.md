# 🔧 Исправление API проблемы

## 🚨 Проблема
- API запрос шел на неправильный порт (5101 вместо 5100)
- Использовался прямой fetch вместо настроенного API инстанса

## ✅ Исправления

### 1. Заменили прямой fetch на API инстанс
```typescript
// Было (неправильно):
const response = await fetch('/api/v2/orders/parse-excel', {
  method: 'POST',
  body: formData,
});

// Стало (правильно):
const response = await api.post('/v2/orders/parse-excel', formData, {
  headers: {
    'Content-Type': 'multipart/form-data',
  },
});
```

### 2. Улучшили обработку ошибок
- Добавлено различение типов ошибок (сервер, сеть, другие)
- Более информативные сообщения об ошибках
- Детальное логирование для диагностики

### 3. Добавили диагностику
- Логирование типа и размера файла
- Отображение базового URL API
- Подробная информация о запросе

## 🎯 Теперь система:
- ✅ Использует правильный порт 5100
- ✅ Работает через единый API инстанс
- ✅ Показывает детальные ошибки
- ✅ Логирует диагностическую информацию

## 🧪 Для тестирования:
1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Загрузите Excel файл
4. Посмотрите детальные логи запроса

Если проблема остается, проверьте:
- Работает ли эндпоинт `/api/v2/orders/parse-excel` на сервере

- Поддерживается ли формат загружаемого Excel файла
