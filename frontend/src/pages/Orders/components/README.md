# Улучшения модуля импорта Excel

## ✅ Выполненные задачи

### 1. Добавлена кнопка для сохранения выбранных заказов
- **Было**: кнопка "Загрузить в базу данных" загружала все заказы
- **Стало**: кнопка "Сохранить выбранные заказы (N)" загружает только выбранные заказы
- Кнопка отключается, если ничего не выбрано
- Показывает количество выбранных заказов

### 2. Добавлен фильтр "Зеленые не загружать"
- **Switch-переключатель** "Исключить зеленые" / "Включить все"
- По умолчанию включен (зеленые заказы исключены)
- Зеленые заказы = заказы с низким приоритетом (дедлайн > 14 дней)
- При включении фильтра автоматически убирает зеленые из выбора
- При отключении фильтра добавляет все заказы в выбор

### 3. Расширенная функциональность выбора
- **Checkbox "Выбрать все"** - выбирает/отменяет все заказы (с учетом фильтра)
- **Row selection** в таблице - можно выбирать отдельные записи
- **Badge с счетчиком** - показывает количество выбранных заказов
- **Цветовое выделение строк**:
  - 🟢 Зеленый фон - низкий приоритет (не срочно)
  - 🟡 Желтый фон - средний приоритет (срочно)  
  - 🔴 Красный фон - высокий приоритет (критично)

### 4. Улучшенная статистика
- Добавлены новые метрики:
  - "Просрочено" - количество просроченных заказов
  - "Выбрано" - количество выбранных для импорта
- Статистика обновляется в реальном времени при изменении выбора
- Расширена с 4 до 6 колонок

### 5. Улучшенный пользовательский интерфейс
- Новая карточка "Фильтры и выбор" с управляющими элементами
- Tooltip с описанием фильтра зеленых
- Обновленные сообщения с учетом количества выбранных заказов
- Индикация прогресса показывает количество выбранных заказов

## 🚀 Текущий статус

✅ **Готово к продакшену**: Все мок-данные удалены, восстановлен оригинальный API.

### Что работает:
1. ✅ Реальный парсинг Excel файлов через API `/api/v2/orders/parse-excel`
2. ✅ Фильтр "Исключить зеленые" работает корректно
3. ✅ Выбор отдельных заказов в таблице
4. ✅ Кнопка "Выбрать все" с учетом фильтров
5. ✅ Счетчик выбранных заказов в реальном времени
6. ✅ Цветовое выделение строк по приоритету
7. ✅ Кнопка "Сохранить выбранные заказы" - сохраняет только выделенное
8. ✅ Сохранение в реальную базу данных через ordersApi

## 🎯 Как использовать

1. **Загрузите Excel файл** - система распарсит его через API
2. **Настройте фильтры**:
   - Включите/отключите фильтр зеленых
   - Выберите нужные заказы вручную
3. **Проверьте выбор** - в статистике видно количество выбранных
4. **Сохраните** - кнопка покажет количество заказов для сохранения

## 🎨 Визуальные улучшения

- Цветовая схема строк по приоритету
- Badge с количеством выбранных
- Switch-переключатель для фильтра
- Расширенная статистика
- Tooltip с подсказками

## 🔧 Техническая реализация

### Новые функции:
- `handleExcludeGreenChange()` - обработка фильтра зеленых
- `handleSelectAll()` - выбор/отмена всех заказов
- `updateStats()` - обновление статистики с учетом выбора

### Новые состояния:
- `excludeGreen` - состояние фильтра зеленых
- `selectedRowKeys` - массив выбранных записей
- `importStats.selected` - количество выбранных в статистике

### Улучшения в UI:
- `rowSelection` в Table для выбора строк
- `rowClassName` для цветового выделения
- CSS стили для цветовых схем строк
- Расширенная карточка статистики
