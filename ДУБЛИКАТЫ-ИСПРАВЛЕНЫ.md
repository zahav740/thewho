## 🚀 Как использовать новую функциональность

### Интерактивный режим (с выбором действий)

```tsx
import { ExcelImportWithDuplicates } from 'components/ExcelImportManager';

// В компоненте
<ExcelImportWithDuplicates />
```

**Процесс:**
1. Пользователь загружает Excel файл
2. Система анализирует и показывает найденные дубликаты
3. Для каждого дубликата пользователь выбирает: заменить/объединить/пропустить
4. Система применяет выбранные действия

### Автоматический режим

```tsx
// Пропустить все дубликаты (безопасный режим)
<ExcelImportWithDuplicates defaultAction="skip" />

// Заменить все дубликаты  
<ExcelImportWithDuplicates defaultAction="replace" />
```

### Программное использование API

```typescript
// 1. Анализ файла
const analysis = await fetch('/api/excel-import-duplicates/analyze', {
  method: 'POST',
  body: formData
}).then(r => r.json());

// 2. Применение решений
const result = await fetch('/api/excel-import-duplicates/process-with-resolutions', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    fileId: analysis.fileId,
    resolutions: {
      resolutions: [
        { orderDrawingNumber: "DWG-001", action: "replace" },
        { orderDrawingNumber: "DWG-002", action: "skip" }
      ],
      defaultAction: "skip"
    }
  })
}).then(r => r.json());
```

## 📊 Типы дубликатов и действия

### 🔄 Действие "Заменить" (replace)
- Полностью удаляет старый заказ
- Создает новый заказ с данными из Excel
- **Используйте:** когда данные в Excel более актуальные

### 🔗 Действие "Объединить" (merge)  
- Обновляет количество (если новое больше)
- Продлевает дедлайн (если новый позже)
- Повышает приоритет (если новый выше)
- Добавляет новые операции, сохраняя старые
- **Используйте:** когда нужно дополнить существующий заказ

### ⏭️ Действие "Пропустить" (skip)
- Оставляет существующий заказ без изменений
- Игнорирует новые данные
- **Используйте:** когда база данных содержит актуальную информацию
