## 🔧 Как запустить аналитику

### 1. Перезапустить Backend
```bash
cd backend
npm run start:dev
```

### 2. Проверить что модуль загружен
Найти в логах:
```
✅ AnalyticsModule loaded
✅ Analytics endpoints registered
```

### 3. Протестировать API
```bash
# Тест базового endpoint
curl http://localhost:5100/api/analytics/kpi-oee

# Ожидаемый результат при пустой БД:
{
  "success": true,
  "data": {
    "shifts": [],
    "aggregated": {
      "overallOEE": 0,
      "overallKPI": 0,
      ...
    }
  }
}
```
