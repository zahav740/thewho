## 🚀 БЫСТРЫЙ ЗАПУСК

### 1. Применить миграцию БД:
```bash
# Windows:
apply-soft-delete-migration.bat

# Linux/Mac:
chmod +x apply-soft-delete-migration.sh
./apply-soft-delete-migration.sh
```

### 2. Запустить backend:
```bash
cd backend
npm run start:dev
```

### 3. Очистить и запустить frontend:
```bash
# Windows:
clean-and-restart-frontend.bat

# Linux/Mac:
chmod +x clean-and-restart-frontend.sh
./clean-and-restart-frontend.sh
```

## 🧪 Тестирование

### Проверка исправлений:

1. **Откройте страницу "База данных"**
2. **Создайте заказ и добавьте операции**
3. **Отметьте некоторые операции как выполненные**
4. **Нажмите кнопку "🔄 Excel (проверка дубликатов)"**
5. **Импортируйте файл с тем же номером чертежа**
6. **Выберите "Умное обновление"**
7. **Проверьте - выполненные операции должны остаться!**

### Проверка soft delete:

1. **Удалите заказ из списка**
2. **Проверьте в БД**: `SELECT * FROM orders WHERE "isDeleted" = true;`
3. **Заказ должен быть помечен как удаленный, но не удален физически**
