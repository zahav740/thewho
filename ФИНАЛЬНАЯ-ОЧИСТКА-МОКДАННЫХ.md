## 🔄 Как теперь работают данные:

### **Источник данных: `shift_records` таблица**

```sql
-- Операторы генерируются динамически:
SELECT DISTINCT dayShiftOperator, nightShiftOperator FROM shift_records;

-- Станки генерируются динамически:  
SELECT DISTINCT m.name FROM shift_records sr 
JOIN machines m ON sr.machineId = m.id;
```

### **API запросы:**
- `GET /api/analytics/kpi-oee` - основные данные
- `GET /api/analytics/operators` - аналитика операторов 
- `GET /api/analytics/machines` - аналитика станков
- `GET /api/analytics/summary` - полная сводка

### **Fallback логика:**
```jsx
// Если нет данных - показываем информативные заглушки
{!isLoading && !error && shiftRecords.length === 0 && (
  <div>Нет данных за выбранный период</div>
)}
```
