## 🚀 Как запустить:

### Backend:
```bash
cd backend
npm install
npm run start:dev
```
**Или используйте:** `ЗАПУСК-BACKEND-ИСПРАВЛЕННЫЙ.bat`

### Frontend:
```bash
cd frontend  
npm install
npm start
```
**Или используйте:** `ЗАПУСК-FRONTEND-ИСПРАВЛЕННЫЙ.bat`
